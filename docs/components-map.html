Before: replies took up to 48 hours. Now: every call is answered, qualified by fixed rules, and qualified leads reach the designers on Telegram within seconds of the transcript arriving.

Built with: Claude Code (build, tests, deploy), GitHub (code), Vercel (app + cron), Neon (Postgres), Vaani AI (voice agent), Telegram Bot API (handoff).

Price rule: the agent never says a price. It reads one approved response, and the audit in steps 16–17 flags any slip after the call.

Trade-off: Vaani offers no mid-call hook, so a price slip by the voice model is caught and flagged after the call, not blocked live. Qualification never depends on the voice model's own verdict.
